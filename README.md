\#  File Organizer



\##  Описание

Приложение для автоматической сортировки файлов по категориям с графическим интерфейсом.



\##  Возможности

\- Выбор папки

\- Сортировка по типам файлов

\- Переименование по шаблону

\- Добавление даты создания



\##  Технологии

\- Python

\- tkinter

\- os, shutil



\##  Запуск

```bash

python main.py
